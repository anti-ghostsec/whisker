# Emoji pictures

72×72 PNGs from [Noto Emoji](https://github.com/googlefonts/noto-emoji)
(`2D/png/72`), one per emoji Whisker offers (see `src/emoji.rs`). Copyright
Google LLC; see `LICENSE` (the repository's licence, SIL Open Font License 1.1;
its README also lists the image resources under Apache 2.0).

File names are the emoji's code points in hex, joined by `_`, without the
U+FE0F variation selector: `emoji_u1f600.png` is 😀.
